# Nutrition Codes

A nutrition coaching website.

## Structure

```
nutrition-codes/
├── index.html
├── about.html
├── testimonials.html
├── blog.html
├── contact.html
├── assets/
│   ├── images/
│   │   ├── hero-bg.jpg
│   │   ├── logo.png
│   │   ├── faculty/        ← amandeep.jpg, ashley.jpg, rishabh.jpg, siddhant.jpg
│   │   └── testimonials/   ← student photos
│   ├── icons/
│   │   └── favicon.png
│   └── videos/
├── css/
│   ├── style.css           ← global styles, variables, navbar, footer
│   ├── home.css
│   ├── about.css
│   ├── testimonials.css
│   ├── blog.css
│   └── contact.css
└── js/
    ├── main.js             ← navbar, scroll, shared logic
    └── contact.js          ← Netlify form handling
```

## Deployment

Deploy via [Netlify](https://netlify.com). Contact form uses Netlify Forms — no backend needed.
